# LLM4S

LLM4S is a Scala-first toolkit for building AI applications. Explore the project at [llm4s/llm4s](https://github.com/llm4s/llm4s).

## Related projects

- **[Triage4s](https://github.com/pavanvamsi3/triage4s)** — An evidence-backed AI triage library and local dashboard for GitHub issues. It uses LLM4S for model calls and requires source evidence for suggested classifications.
- **[Typesafe4s](https://github.com/gruggiero/typesafe4s)** — A Scala 3 SDK for TypeSafe System One, providing typed questions and answers across Scala effect systems.
